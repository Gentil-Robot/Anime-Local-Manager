# Notice d'utilisation

## 1. Lancer

Double-clique sur `Lancer Anime Manager.bat`.

## 2. Choisir une sauvegarde cloud

Clique sur `Réglages`, puis indique un dossier synchronisé par ton cloud.

Ce n'est pas un stockage direct dans le cloud : l'application sauvegarde dans un dossier local que ton cloud synchronise ensuite.

## 3. Mettre à jour depuis une ancienne version

Clique sur `Réglages`, renseigne le chemin de l'ancien dossier et clique sur `Importer ancienne version`.

## 4. Changer l'affichage

Utilise le menu `Vue cartes`, `Vue compacte` ou `Vue liste`.

## 5. Détecter les nouvelles saisons

Clique sur `News saisons`.

Clique sur un titre pour charger son image et sa description.

## 6. Sauvegarder manuellement

Clique sur `Réglages`, puis `Sauvegarder maintenant`.
